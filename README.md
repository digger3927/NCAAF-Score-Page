# 🏈 NCAAF Score Page

A lightweight, vanilla HTML/JS single-page application for tracking live NCAA College Football scores, schedules, standings, and detailed play-by-play metrics in real-time.

## ✨ Features
- **Live Scoreboard**: Real-time game statuses pulling straight from the ESPN API.
- **Interactive Play-by-Play**: Click any game to view a live, auto-refreshing detailed box score and chronological play-by-play breakdown.
- **Dynamic Win Probability**: Center-aligned tug-of-war slider showing real-time win probability with dynamic team colors.
- **Conference Filtering**: Filter the scoreboard and standings by specific FBS/FCS conferences dynamically sourced from the NCAA API.
- **Top 25 Rankings**: AP Top 25 rankings automatically displayed next to team names.
- **TV Broadcasts**: Easily see which television networks are broadcasting scheduled games.
- **Dark Mode Support**: Fully responsive UI that honors your system's `prefers-color-scheme` settings.

## 🚀 Getting Started
No build processes, package managers, or local servers required.
1. Clone the repository.
2. Open `index.html` in any modern web browser.

## 🛠️ Technologies Used
- HTML5 / CSS3 / Vanilla JavaScript
- ESPN Public API
